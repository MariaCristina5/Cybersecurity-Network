# Cybersecurity & Network Security Lab
## Overview

This project was completed as part of a university Cybersecurity course and focuses on secure remote access, basic Linux administration, PowerShell, and Windows Firewall configuration.
The practical work involved using an Ubuntu Linux virtual machine to demonstrate an SSH connection and remote command execution, as well as using Windows PowerShell to examine Windows Firewall rules and configurations.

## Objectives
- Set up and use an Ubuntu Linux virtual machine as a remote SSH environment.
- Establish an SSH connection between systems using OpenSSH.
- Execute commands through an SSH connection.
- Explore Windows Firewall rules and configurations using PowerShell.
- Test PowerShell functions for retrieving and displaying firewall information.
- Document the procedures, commands, configurations, and results.
## Tasks
## 1. SSH Connection – Ubuntu Linux Virtual Machine

An Ubuntu Linux virtual machine was used to demonstrate remote access through SSH.
The practical work included:

- Setting up an Ubuntu Linux environment in a virtual machine.
- Establishing an SSH connection to the Linux machine.
- Executing remote commands through the SSH connection.
- Demonstrating communication between the systems using the SSH protocol.
- Documenting the connection process and command execution.

## 2. Windows Firewall – PowerShell
- PowerShell was used to examine Windows Firewall rules and configurations.
- Two PowerShell functions were tested:
- A function for retrieving firewall rules associated with the Public firewall profile.
- A function for displaying selected firewall rule properties, including display name, enabled status, direction, and action.

## The following PowerShell concepts and commands were explored:

- Get-NetFirewallProfile
- Get-NetFirewallRule
- Select-Object
- Format-List
- PowerShell functions
